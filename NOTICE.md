# Attribution and security scope

This Windows overlay is built from the MIT-licensed open source project by soleillevant0125:

https://github.com/soleillevant0125/codex-token-overlay

The original MIT LICENSE is retained. The unmodified upstream documentation is available in UPSTREAM.md. Source code is attributed to its original author; TunnelLab adds distribution documentation and a GitHub Actions packaging workflow.

The app is a separate, read-only, local companion for Codex Desktop. It reads JSONL session logs and listens to the local named pipe; it does not inject into Codex, install browser extensions, or contact external servers. Read the source and verify artifact checksums before running unsigned community software.
